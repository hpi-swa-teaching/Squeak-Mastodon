A MTLoginCredentials is an Object used to store login credentials for one Mastodon account.

Instance Variables
	baseURL:		<String>
	token:		<String>
	username:		<String>

baseURL
	- The base URL of the provider where these credentials are used.

token
	- Login token provided by the Mastodon/Bluesky server.

username
	- unique identifier to log in on the server
