A MTUISortFilter is an object that displays all buttons needed for the sorting filters. Also it notifies its observers on change and implements a bit of logic needed for sorting.

Instance Variables
	observers:		<Object>
	sortDirection:		<Object>
	sortKey:		<Object>

observers
	- collection of observers

sortDirection
	- direction to sort (ascending/descending)

sortKey
	- which key should be sorted by
