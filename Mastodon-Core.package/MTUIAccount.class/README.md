A MTUIAccount is an object that renders an account and information about it.

Instance Variables
	account:		<Object>
	actions:		<Object>
	avatar:		<Object>
	blockButton:		<Object>
	content:		<Object>
	directTootButton:		<Object>
	followButton:		<Object>
	image:		<Object>
	note:		<Object>
	text:		<Object>

account
	- a provider account

actions
	- a morph that bundles all buttons together

avatar
	- profile picture of the account

blockButton
	- button used to block the shown user

content
	- a morph with all shown content

directTootButton
	- button used to direct toot to the shown user

followButton
	- button that follows the shown user

image
	- an image morph of the avatar

note
	- personal note

text
	- text morph with account data
